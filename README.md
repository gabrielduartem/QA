# QA Práticas – Testes Automatizados e Gherkin

Este repositório contém meus exercícios e estudos de QA, incluindo:
- Casos de teste automatizado para sites de prática (Playground, SauceDemo)
- Cenários escritos em Gherkin
- Cucumber
- Cypress

## Ferramentas usadas
- Gherkin
- Visual Studio Code
- Cypress
- Sites de prática: Playground, SauceDemo

## Como usar
- Abra os arquivos `.feature` para ver os cenários em Gherkin
- Abra o Visual Studio Code e inicie o Cypress
